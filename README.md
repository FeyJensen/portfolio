# Fey Jensen Portfolio

A modern single-page portfolio built with React and Vite for a freelance web designer and developer.

## Features

- Clean, responsive landing page
- Hero section with personal branding and headshot
- Services overview
- About section
- Contact call-to-action
- Built with React + Vite

## Tech Stack

- React
- Vite
- CSS

## Local Development

```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal, typically:

```bash
http://localhost:5173/
```

## Production Build

```bash
npm run build
```

## Deployment

This project is ready to deploy on Vercel or any static hosting provider.
